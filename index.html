dbshDatabase migrations that ship

A Flyway-style migration tool for PostgreSQL, SQL Server, MySQL, SQLite, Oracle, CockroachDB, YugabyteDB, and Aurora. Beautiful CLI, zero magic, production-tested patterns.

GitHub
📝

SQL-first

Plain .sql files. No embedded DSL, no XML, no surprises. You write SQL, dbsh tracks and applies it.

🗄️

Multi-database

One tool, eight engines. PostgreSQL, SQL Server, MySQL, SQLite, Oracle, CockroachDB, YugabyteDB, and Aurora. Switch providers without changing your workflow.

🔒

Safe by design

Distributed locks, approval gates, deployment windows, and audit trails. Production-grade safety built in.

⚡

CI-friendly

Every command supports --json output and deterministic exit codes. Plug it into any CI/CD pipeline.

📴

Works offline

Validate, plan, and scaffold without a database connection. Use --in-memory for offline workflows.

🔍

Checksum integrity

SHA-256 checksums detect when previously-applied scripts are edited. No silent drift in production.
